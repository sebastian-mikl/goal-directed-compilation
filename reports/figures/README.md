## Flags (read before drafting)

1. **The task's example numbers are pre-retier.** The task text cites "115/140" and
   "82.1% / 92.9% / 85.7% / 76.4% / 70.0%" — those are the DRAFT (140-cell) numbers.
   The locked data is **135-cell** (wta_15 retiered to out-of-contract), so Fig 1/2
   and Table 3 render at network 85.2% acc / 11.1% silent, text-to-SQL 92.6/7.4, etc.
   This is expected and correct — figures follow the locked CSV, not the task text.

2. **The thesis figure (Fig 2) does not favor network under *strict* scoring.**
   Network's strict Spider silent-error (11.1%) sits above text-to-SQL (7.4%). It is
   *only* under tie-tolerant scoring (Fig 2t: network 3.7%, lowest) that Spider
   supports the thesis — because the strict gap is the two pandas-vs-SQLite tie
   artifacts (world_13, bike_06). The thesis reads cleanly on **employee** regardless
   (network 4.9% silent vs 14–17% for every baseline; Table 2). Recommend leading the
   silent-error argument with employee + the tolerant Spider figure, per
   `reports/paper_numbers.md`.

3. **No value differs from `paper_numbers.md`.** Every plotted number was
   cross-checked against the locked CSV and the md tables; all match.
